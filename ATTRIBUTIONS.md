# Third-party catalog attribution

CSELL uses the open community dataset and item images made available by [ByMykel/CSGO-API](https://github.com/ByMykel/CSGO-API) and [ByMykel/counter-strike-image-tracker](https://github.com/ByMykel/counter-strike-image-tracker). The catalog refresh workflow downloads the latest CS2 game item data daily; images are served from their published image URLs.

Both upstream repositories publish an MIT license. The notices for both are included here for the catalog distribution.
